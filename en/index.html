The time hub for exam rooms

Aeterna

Clear, dependable exam schedule playback and room timing. Create or import a schedule, then present exam state and a countdown on a large display.

Get the latest releaseRelease notes

Open source · GPL-3.0 · Rust + Qt 6 · no account required

Built for exam rooms

Bring the schedule, time and display information into one clear, rehearsable workflow.

◷

Schedule editing and validation

Create, order and validate sessions, including timings, advance reminders, notices and materials.

▣

Fullscreen room player

Use an independent large-display window for subject, countdown, room number, notices and status.

{ }

JSON import and export

Save, reuse, back up and hand over schedules as UTF-8 JSON configuration files.

⌁

NTP time checks

Test a server, synchronize network time and enable automatic time checks when appropriate.

◎

LAN device discovery

Discover Aeterna devices on the LAN with mDNS; verify behaviour in your own network environment.

◐

Adaptable appearance

Light, dark, system-following and custom-primary-colour settings support different display environments.

Experimental network capabilities

Some HTTP configuration and LAN delivery capabilities are still evolving. Do not make them the sole safeguard in a critical exam workflow; use the current release notes and an on-site rehearsal.

Three steps to room timing

Run one complete rehearsal before the actual exam.

  1. 01

    Get the matching release file

    Download the latest release executable for your operating system and architecture from the official GitHub Release.

  2. 02

    Edit, import and check the schedule

    Check session names, times, reminders, notices and materials; save or export JSON as a backup.

  3. 03

    Check time, play fullscreen, rehearse

    Check system or NTP time, open the player and rehearse on the real display hardware.
