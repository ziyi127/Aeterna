为考场而生的能力

从真实时间推进到跨屏投送，Aeterna 把复杂的考场计时变成一件简单可靠的事。

真实时间自动推进

在开始、结束与结束前提醒时自动切换状态，无需人工计时。

面向大屏的播放器

独立播放窗口，清晰展示科目、倒计时、考场号与公告。

可视化日程编辑

创建、排序与校验多场考试，时间、提醒与材料清单一目了然。

多屏与远程能力

局域网设备发现投屏，并提供 HTTP API 供集成控制。

NTP 校时

对时间准确性要求高的考场，支持网络时间校准。

跨平台运行

Windows、macOS、Linux 原生支持，含浅色、深色与高对比度外观。

三步，进入考场计时

下载即用，无需复杂配置。完整流程一次演练即可上线。

1

下载并运行

从 Release 获取对应系统的包，解压后直接启动 Aeterna。

2

新建 / 编辑日程

在首页填写考试名称、时间、提醒与材料，保存为 JSON。

3

载入并播放

载入日程、打开播放器，开始前核对系统时间即可开考。
