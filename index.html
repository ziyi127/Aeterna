考试现场的时间中枢

Aeterna

可靠、清晰的考试日程播放与考场计时应用。创建或导入日程，在大屏上准确呈现考试状态与倒计时。

开源 · GPL-3.0 · Rust + Qt 6 · 无需账户即可使用

为考试现场而生

把日程、时间和屏幕信息集中到一个清晰、可演练的流程中。

◷

日程编辑与校验

创建、排序和校验多场考试；设置开始结束时间、结束前提醒、公告与材料清单。

▣

全屏考场播放器

在独立大屏窗口清晰展示科目、倒计时、考场号、公告与当前状态。

{ }

JSON 导入与导出

用 UTF-8 JSON 配置保存、复用、备份和转交考试日程。

⌁

NTP 校时

在考前测试服务器、同步网络时间，并按需要启用自动校时。

◎

局域网设备发现

通过 mDNS 发现局域网内的 Aeterna 设备；请以实际网络环境和发布说明为准。

◐

适应现场环境

提供浅色、深色、跟随系统和自定义主色等外观设置，便于不同显示环境阅读。

关于实验性网络能力

部分 HTTP 配置与局域网投送能力仍在演进中，不应替代考前演练或作为关键考务流程的唯一保障。请以当前 Release 说明和实际设备测试结果为准。

三步，进入考场计时

建议在正式考试前完成一次端到端演练。

01

获取匹配的发布包

从官方 GitHub Release 下载与你的系统和架构匹配的 最新版 可执行文件。

02

编辑、导入并核对日程

检查考试名称、时段、提醒、公告和材料；保存或导出 JSON 作为备份。

03

校时、全屏播放与演练

核对系统或 NTP 时间，打开播放器，并用实际显示设备完成一次演练。
