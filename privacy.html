隐私说明

本页面说明 Aeterna 官网使用的第三方服务、广告同意选择及其影响。最后更新：2026-08-02。

网站托管与下载

本静态站点通过 GitHub Pages 提供。下载链接会将你带到 GitHub Releases；GitHub 及其服务会按照其自身隐私政策处理访问请求。Aeterna 不要求注册账户即可浏览官网或下载发布文件。

广告的同意选择

在你点击“同意并加载广告”前，本站不会加载 Google AdSense 脚本。选择会保存于浏览器本地存储，用于记住偏好。拒绝不会影响页面内容、GitHub 链接或下载。你可在页脚通过“隐私与广告设置”重新打开选择框。

Google AdSense

当你同意后，Google AdSense 可能请求和处理设备标识符、IP 地址、浏览器信息及使用数据，以展示和衡量广告。其处理方式受 Google 的隐私政策、你的地区及广告设置影响。请在发布商账户中确认适用地区所需的 CMP、Consent Mode 或 IAB TCF 设置。

本地存储

本站仅使用本地存储项 aeterna-ad-consent-v1 保存广告同意状态。删除浏览器站点数据会清除该选择并可能再次显示同意提示。

第三方链接

GitHub、Google 和其他外部网站不受本说明控制。请阅读其各自的条款和隐私政策后再继续访问、下载或同意广告。

联系我们

如对本站内容、下载或隐私说明有疑问，请通过 GitHub Issues 提交反馈。

你可以随时修改广告选择。
